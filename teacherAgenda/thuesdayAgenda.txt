💻 Code-along – Skapa första React-appen med Vite

🎯 Syfte:
Inte att memorera kod – utan att se hur ett React-projekt kommer till
och hur delarna hänger ihop.

🗣️
“Nu vill jag att ni tittar mer än skriver.
Ni får gärna testa själva sen – men just nu är fokus förståelse.”

Om någon inte har Node installerat – det är helt okej.
Ni har inte gjort något fel.
Det här är första gången vi lämnar vanilla JavaScript på riktigt.”
👉 Installera i lugn och ro efter lektionen eller imorgon

”Vill ni snabbt kolla om ni har Node:
skriv node -v i terminalen.

”Hittills har ni jobbat med JavaScript i webbläsaren.
Då är det webbläsaren som kör JavaScript.”

”Node.js gör så att JavaScript kan köras utanför webbläsaren – till exempel i terminalen.”

”Vi använder inte Node för att skriva backend just nu.
Vi använder Node för att:
– starta projekt
– installera verktyg
– köra utvecklingsservern”

”React kräver inte Node i produktion –
men vi behöver Node när vi utvecklar.”

--------------------------------------------------

📂 Steg 0 – Starta repo (lokalt)

1. Skapa en ny mapp på datorn, t.ex:
   FE25-react-intro

2. Öppna mappen i VS Code

3. Öppna terminalen i VS Code

--------------------------------------------------

🧪 Steg 1 – Skapa React-projektet med Vite

I terminalen:

npm create vite@latest

• Projekt-namn: react-intro
• Välj: React
• Välj: JavaScript

🗣️
“Detta kommando skapar hela grundstrukturen åt oss.”

--------------------------------------------------

📦 Steg 2 – Installera dependencies

cd react-intro
npm install

🗣️
“Nu laddas alla paket som projektet behöver.
Detta görs bara en gång per projekt.”

--------------------------------------------------

🚀 Steg 3 – Starta utvecklingsservern

npm run dev

🗣️
“Nu startar vår utvecklingsserver.
Länken i terminalen öppnas i webbläsaren.”

--------------------------------------------------

📁 Steg 4 – Titta på projektstrukturen

Visa i VS Code:

• node_modules/ (rör vi inte)
• public/
• src/
  – main.jsx
  – App.jsx

------------

- Projektets rotmapp (react-intro)
”Det här är projektets rotmapp.
Allt som hör till vår app finns här.”

- ”node_modules innehåller all kod vi har installerat via npm.”
”Vi:
– läser inte här
– ändrar inte här
– skickar inte med denna mapp till GitHub”

”Om ni tar bort node_modules kan den återskapas med npm install.”

------------

- ”package.json är projektets konfigurationsfil.”

”Här står:
– projektets namn
– vilka paket som används
– vilka script vi kan köra”

”När vi skriver npm run dev –
då är det ett script som är definierat här.”

------------

- ”src är där vi jobbar.
Det är här vår kod bor.”

”Om ni är osäkra på var ni ska skriva kod –
då är svaret nästan alltid: src.”

------------

- ”main.jsx är startpunkten för React.”
”Den kopplar React till HTML-sidan.”
”Vi ändrar sällan här – den bara startar appen.”

------------

- “App.jsx är vår rotkomponent, vår första komponent.”
”Det är här vi börjar bygga vår app.”

”Allt vi ser i webbläsaren just nu kommer från App.jsx.”

------------

- ”public innehåller statiska filer – till exempel bilder eller favicon.”
”Vi använder den sällan i början.”

------------

- Övriga mappar och filer (KAN VÄNTA)

”Vi kommer senare prata om:
– fler komponenter
– props
– state
– routing
– API:er”

”Ni behöver inte förstå allt idag.
React byggs lager för lager.”

--------------------------------------------------

✂️ Steg 5 – Rensa App.jsx

Öppna src/App.jsx

Ta bort allt innehåll och skriv:

function App() {
  return <h1>Hello React</h1>;
}

export default App;

🗣️
“Det här är React i sin enklaste form:
en funktion som returnerar UI.”

--------------------------------------------------

🔄 Steg 6 – Kontrollera i webbläsaren

• Sidan uppdateras automatiskt
• Ingen reload behövs

🗣️
“Detta är en av styrkorna med React + Vite.”
