💻 Code-along – Start på Todo-app (React)

🎯 Syfte:
– Förstå JSX i praktiken
– Lära sig funktionella komponenter
– Förstå komponenttänk
– Skicka data med props
– Skapa struktur som vi bygger vidare på imorgon (useState)

🗣️
“Idag bygger vi grunden till en Todo-app.
Den kommer inte vara interaktiv än – och det är helt medvetet.”

“Fokus idag är struktur och tänk – inte logik.”

--------------------------------------------------

📁 Steg 1 – Skapa projektstruktur

I src/ skapar vi:

src/
 ├─ components/
 │   ├─ TodoApp.jsx
 │   ├─ TodoHeader.jsx
 │   ├─ TodoList.jsx
 │   └─ TodoItem.jsx
 ├─ App.jsx
 └─ main.jsx

🗣️
“Varje fil representerar en del av gränssnittet, inte logik.”

--------------------------------------------------

🧩 Steg 2 – App.jsx (rotkomponent)

Öppna src/App.jsx och skriv:

import TodoApp from "./components/TodoApp";

function App() {
  return <TodoApp />;
}

export default App;

🗣️
“App.jsx är vår rot – men den innehåller nästan ingen logik.”

--------------------------------------------------

🧩 Steg 3 – TodoApp.jsx (container-komponent)

Skapa src/components/TodoApp.jsx:

import TodoHeader from "./TodoHeader";
import TodoList from "./TodoList";

function TodoApp() {
  return (
    <div>
      <TodoHeader />
      <TodoList />
    </div>
  );
}

export default TodoApp;

🗣️
“TodoApp sätter ihop flera komponenter.
Den är som själva sidan.”

--------------------------------------------------

🧩 Steg 4 – TodoHeader.jsx

Skapa src/components/TodoHeader.jsx:

function TodoHeader() {
  return (
    <header>
      <h1>My Todo App</h1>
      <p>Saker jag behöver göra</p>
    </header>
  );
}

export default TodoHeader;

🗣️
“En komponent är bara en funktion som returnerar JSX.”

--------------------------------------------------

🧩 Steg 5 – TodoList.jsx (hårdkodad lista)

Skapa src/components/TodoList.jsx:

import TodoItem from "./TodoItem";

function TodoList() {
  return (
    <ul>
      <TodoItem text="Lära mig React" />
      <TodoItem text="Förstå komponenter" />
      <TodoItem text="Jobba med props" />
    </ul>
  );
}

export default TodoList;

🗣️
“Just nu är detta statisk data.
Imorgon gör vi den dynamisk.”

--------------------------------------------------

🧩 Steg 6 – TodoItem.jsx (props)

Skapa src/components/TodoItem.jsx:

function TodoItem({ text }) {
  return <li>{text}</li>;
}

export default TodoItem;

🗣️
“Props är data som skickas in i en komponent.”
“Här är text ett värde vi bara visar upp.”
